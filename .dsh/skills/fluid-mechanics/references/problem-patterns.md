# 常见题型与公式选择

## 1. 水库 → 管道 → 大气

取水库液面 1 和出口 2：

\[
H=\frac{v_2^2}{2g}+h_f+h_j.
\]

先用连续性把各段速度表示成一个未知速度，再解能量方程。

**检查**：出口速度水头是总水头的一部分，不是额外损失。

## 2. 两段串联管

\[
v_1A_1=v_2A_2,
\]

\[
H=\frac{v_2^2}{2g}
+K_1\frac{v_1^2}{2g}
+K_2\frac{v_2^2}{2g}.
\]

令 \(r=A_2/A_1\)，则 \(v_1=rv_2\)，速度水头 \(h_{v1}=r^2h_{v2}\)：

\[
H=h_{v2}\left(1+K_1r^2+K_2\right).
\]

先求 \(h_{v2}\)，再求 \(v_2,v_1\)。

## 3. 虹吸管

从上游液面到虹吸最高点列能量方程：

\[
\frac{p_{\text{顶}}}{\rho g}
=H-\frac{v^2}{2g}-h_f-z_{\text{顶}}.
\]

最高点通常出现最低压强。必须检查：

\[
p_{\text{顶}}>p_{\text{汽化}},
\]

否则会汽化、断流。虹吸的流量由上下游液面高差和总损失决定，不是由最高点
高度决定。

## 4. 孔口/管嘴出流

小孔口自由出流：

\[
Q=C_dA\sqrt{2gH}.
\]

其中 \(C_d\) 包含收缩、速度系数等经验修正。若题目给“理想流体、无损失”，
则 \(C_d=1\)。不要同时用 \(C_d\) 又额外加局部损失，除非题意明确。

## 5. 泵/水轮机

泵：

\[
H_1+\frac{p_1}{\gamma}+\frac{v_1^2}{2g}+H_{\text{泵}}
=
H_2+\frac{p_2}{\gamma}+\frac{v_2^2}{2g}+h_f.
\]

水轮机：

\[
H_1+\frac{p_1}{\gamma}+\frac{v_1^2}{2g}
=
H_2+\frac{p_2}{\gamma}+\frac{v_2^2}{2g}+h_f+H_{\text{轮机}}.
\]

泵的 EGL 向上跳，水轮机的 EGL 向下跳。泵的轴功率：

\[
P_{\text{轴}}=\frac{\rho gQH_{\text{泵}}}{\eta}.
\]

## 6. 测压管/压力计

静水压强：

\[
p=\rho g h.
\]

U 形管压差计：

\[
p_1-p_2=(\rho_m-\rho)g\Delta h
\]

（具体符号按左右支管液面高低判断）。先画等压面，再列静水方程。

## 7. 串联与并联管道

串联：

\[
Q_1=Q_2=\cdots,\qquad h_f=\sum h_{fi}.
\]

并联：

\[
h_{f1}=h_{f2}=\cdots,\qquad Q=\sum Q_i.
\]

并联各支管水头损失相同，但流量按阻抗分配。不要直接把流量相加后
再用总长度算损失。

## 8. 孔口/管嘴与管道系统

如果孔口后接管道，先判断控制断面：孔口、管出口还是收缩断面。
一般从上游液面到控制断面列能量方程，损失包括进口、沿程、局部和出口
（若排入水池）。排入大气时不要重复计算出口损失。

## 9. 明渠（暂不在 V0 范围）

明渠流不能用有压管流的 EGL/HGL 直接套。需要区分均匀流、渐变流、
急变流，并使用曼宁公式、比能、临界水深等。遇到时先说明模型边界。

## 10. 选题速查

| 题目关键词 | 首选方程 | 关键检查 |
|---|---|---|
| 水库、管道、出口 | 连续性 + 伯努利 | 出口 \(p=0\) |
| 两段面积不同 | 连续性 + 能量 | 面积比，不是直径比 |
| 水头线/测压管 | EGL/HGL 关系 | 速度水头间距 |
| 虹吸 | 伯努利 + 负压 | 汽化压强 |
| 孔口/管嘴 | 孔口公式 | \(C_d\) 是否给 |
| 泵/水轮机 | 能量方程 | 加入/提取水头方向 |
| 压差计 | 静水方程 | 等压面 |
| 串联/并联 | 连续性 + 损失分配 | 流量/水头关系 |
