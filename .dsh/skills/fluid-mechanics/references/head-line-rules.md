# 水头线细则

## 1. 定义

取管轴为基准面 \(z=0\) 时：

\[
\mathrm{HGL}=z+\frac{p}{\rho g},
\qquad
\mathrm{EGL}=z+\frac{p}{\rho g}+\frac{v^2}{2g}.
\]

因此：

\[
\mathrm{HGL}=\mathrm{EGL}-\frac{v^2}{2g}.
\]

- EGL：单位重量流体的总机械能水头。
- HGL：测压管水头，也就是测压管液面到基准面的高度。
- 两者竖直间距：速度水头 \(v^2/(2g)\)。
- 水平管 \(z=0\)：\(p/\gamma=\mathrm{HGL}\)。

## 2. 画线规则

### 2.1 水库

自由液面处 \(v\approx0,\ p=0\)，所以：

\[
\mathrm{EGL}=\mathrm{HGL}=H.
\]

水库内部静水压强随深度增加，但 \(p/\gamma+z\) 仍等于自由液面高度，
所以 HGL 与自由液面重合。

### 2.2 等直径管、无损失

\[
\mathrm{EGL}=\text{常数},\qquad
\mathrm{HGL}=\mathrm{EGL}-\frac{v^2}{2g}.
\]

两条线都水平，HGL 在下，间距为速度水头。

### 2.3 等直径管、有沿程损失

沿流向：

\[
\mathrm{EGL}_2=\mathrm{EGL}_1-h_f.
\]

若损失沿管长均匀分布，则 EGL 是直线，坡度：

\[
J=\frac{h_f}{L}.
\]

同一段管内 \(v\) 不变，所以：

\[
\mathrm{HGL}=\mathrm{EGL}-\frac{v^2}{2g}
\]

也与 EGL 平行，坡度同为 \(J\)。

> 题目没给管长时，不能确定真实坡度；只能画示意直线，并注明
> “横向长度未按比例”。若两段损失分别为 \(h_{f1},h_{f2}\)，
> 真实坡度为 \(J_1=h_{f1}/L_1\)、\(J_2=h_{f2}/L_2\)。

### 2.4 收缩/放大、不计局部损失

连续方程使速度改变，速度水头改变：

\[
\Delta h_v=\frac{v_2^2}{2g}-\frac{v_1^2}{2g}.
\]

- EGL 连续（没有局部损失）；
- HGL 竖直突变 \(\Delta h_v\)；
- 收缩：\(v_2>v_1\)，HGL 向下跳；
- 放大：\(v_2<v_1\)，HGL 向上跳。

### 2.5 局部损失

局部损失 \(h_j\) 集中在阀门、弯头、突然收缩等处：

- EGL 在该位置竖直下降 \(h_j\)；
- HGL 的变化为 \(h_j+\Delta h_v\)（向下为损失，向上为速度水头减小）；
- 若题目说“不计局部损失”，不要画这个竖直下降。

### 2.6 出口

自由射流进入大气：

\[
p_{\text{出口}}=0,
\]

所以：

\[
\mathrm{HGL}=z_{\text{出口}},
\qquad
\mathrm{EGL}=z_{\text{出口}}+\frac{v_{\text{出口}}^2}{2g}.
\]

若出口在管轴基准面上，则 HGL \(=0\)，EGL \(=v_{\text{出口}}^2/(2g)\)。

**不要**再把 \(v^2/(2g)\) 当成“出口损失”重复扣除；它已经包含在
出口断面的总水头里。

### 2.7 泵和水轮机

泵加入能量：

\[
\mathrm{EGL}_{\text{出}}=\mathrm{EGL}_{\text{入}}+H_{\text{泵}},
\]

EGL 向上跳；HGL 也向上跳，但同时受速度水头变化影响。

水轮机提取能量：

\[
\mathrm{EGL}_{\text{出}}=\mathrm{EGL}_{\text{入}}-H_{\text{轮机}},
\]

EGL 向下跳。

## 4. 作图检查清单

- [ ] 标了基准面 \(z=0\) 和水库液面高度 \(H\)。
- [ ] EGL 从水库液面开始，不是从管口开始。
- [ ] 无损失段 EGL 水平；有沿程损失段 EGL 斜向下。
- [ ] HGL 与 EGL 的间距等于该段速度水头。
- [ ] 收缩处 EGL 连续（不计局部损失），HGL 有竖直跌落。
- [ ] 出口 HGL 等于出口位置水头，EGL 比它高一个出口速度水头。
- [ ] 图中标了 \(v_1,v_2\)、\(A_1,A_2\) 和关键水头数值。
- [ ] 若横向长度任意，注明“未按比例”。

## 5. 常见错误对照

| 错误画法 | 正确画法 |
|---|---|
| 有沿程损失，EGL 仍水平 | EGL 沿流向下降 |
| 有沿程损失，HGL 水平 | HGL 与 EGL 平行下降 |
| 收缩处 EGL 竖直下降，但题目不计局部损失 | EGL 连续，仅 HGL 跳变 |
| 出口 HGL 等于 EGL | 出口 HGL 比 EGL 低 \(v^2/(2g)\) |
| 把 HGL 当作总能量 | HGL 只是压力水头+位置水头 |
| 用直径比算速度比 | 用面积比 |
